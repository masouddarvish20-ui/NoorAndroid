# ذکران 2.3.3

نسخه 2.3.3 با تمرکز بر ساده‌سازی تجربه کاربری، صفحه خانه خلوت‌تر و منوی کاربردی‌تر.

## ساخت APK

پروژه با JDK 17، Android Gradle Plugin 8.7.3 و Gradle 8.9 ساخته می‌شود.
GitHub Actions در هر Push یا اجرای دستی، APK دیباگ را تولید و به‌عنوان artifact ذخیره می‌کند.
