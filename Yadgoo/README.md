# یادگو — نسخه آزمایشی ۰.۲ اندروید

پروژه را در Android Studio باز کنید، اجازه دهید Gradle همگام شود و از Run برای نصب استفاده کنید. حداقل Android 8 و Android SDK 35 لازم است. بسته APK از مسیر Build > Build APK(s) ساخته می‌شود.

## امکانات فعلی

- ثبت متن با گفتار فارسی از سرویس تشخیص گفتار نصب‌شده روی گوشی، با امکان اصلاح متن پیش از ذخیره
- ثبت محلی یادداشت‌ها و کارها، دسته‌بندی خودکار بر پایه واژه‌های مشخص یا انتخاب دستی، امروز، صندوق، پروژه‌ها و جست‌وجو
- ضبط اختیاری فایل صوتی، ذخیره در حافظه خصوصی برنامه و پخش دوباره آن از کارت یادداشت. ضبط صوت و تشخیص گفتار فعلاً جداگانه انجام می‌شوند.
- یادآوری برای عبارت‌های «امروز»، «فردا» و «یک روز فرصت» همراه با «ساعت ۹» یا پیش‌فرض ۹ صبح؛ اعلان ممکن است با محدودیت باتری گوشی با تأخیر برسد
- انجام‌شده، ویرایش متن و حذف؛ با این عملیات زمان‌بندی اعلان نیز لغو یا دوباره تنظیم می‌شود.

## محدودیت‌های مشخص نسخه اولیه

تبدیل گفتار ممکن است بسته به سرویس دستگاه اینترنت بخواهد. ضبط فایل صوتی به تنهایی متن تولید نمی‌کند؛ برای متن باید جداگانه از دکمه تشخیص گفتار یا صفحه‌کلید استفاده کنید. تحلیل معنایی پیشرفته، ارجاع به کارهای قبلی، شکستن یک جمله به چند کار، تاریخ شمسی و همگام‌سازی هنوز پیاده نشده‌اند. عبارت‌های مبهم زمانی در صندوق می‌مانند. پاک شدن داده برنامه، داده‌ها و صداهای ذخیره‌شده را حذف می‌کند. پس از راه‌اندازی دوباره گوشی، یادآوری‌های قبلی هنوز بازگردانی نمی‌شوند. این نسخه با کلید آزمایشی سرور امضا شده است و ممکن است برای نصب روی نسخه آزمایشی ۰.۱ نیاز به حذف نسخه قبلی باشد؛ حذف برنامه همه داده‌های آن را پاک می‌کند. برای اطلاعات حساس کاری از داده واقعی تا افزودن بکاپ و حفاظت استفاده نکنید.
