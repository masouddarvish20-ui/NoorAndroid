# یادگو — نسخه اولیه اندروید

پروژه را در Android Studio باز کنید، اجازه دهید Gradle همگام شود و از Run برای نصب استفاده کنید. حداقل Android 8 و Android SDK 35 لازم است. بسته APK از مسیر Build > Build APK(s) ساخته می‌شود.

## امکانات فعلی

- ثبت متن با گفتار فارسی از سرویس تشخیص گفتار نصب‌شده روی گوشی، با امکان اصلاح متن پیش از ذخیره
- ثبت محلی یادداشت‌ها و کارها، دسته‌بندی خودکار بر پایه واژه‌های مشخص یا انتخاب دستی، امروز، صندوق، پروژه‌ها و جست‌وجو
- یادآوری برای عبارت‌های «امروز»، «فردا» و «یک روز فرصت» همراه با «ساعت ۹» یا پیش‌فرض ۹ صبح؛ اعلان ممکن است با محدودیت باتری گوشی با تأخیر برسد
- انجام‌شده، ویرایش متن و حذف

## محدودیت‌های مشخص نسخه اولیه

فایل خام صدا نگهداری نمی‌شود. تبدیل گفتار ممکن است بسته به سرویس دستگاه اینترنت بخواهد. تحلیل معنایی پیشرفته، ارجاع به کارهای قبلی، شکستن یک جمله به چند کار، تاریخ شمسی و همگام‌سازی هنوز پیاده نشده‌اند. عبارت‌های مبهم زمانی در صندوق می‌مانند. پاک شدن داده برنامه، داده‌های ذخیره‌شده را حذف می‌کند. ویرایش متن یادآوری موجود را دوباره تنظیم نمی‌کند؛ یادآوری حذف‌شده هم باید در نسخه بعد لغو شود. برای اطلاعات حساس کاری از داده واقعی تا افزودن بکاپ و حفاظت استفاده نکنید.
